# FIELD-NOTES.md: your private working notes

Not graded. Not submitted. Nobody reads this but you.

After each session, apply the same capability to one real repository. Record
what happened while you still remember it. Keep the notes privacy-safe. Name
shapes, not secrets.

Two fields carry the weight. **Observation** must hold pasted text, not memory:
the probe row, the refusal, or the check output. The next session asks you for
**Retained change**, and the Compound row of your run card comes from it.

When a note becomes something the run card asks for, put the link in
`PROOF.md`. The note stays here. This file is never a second copy of your
evidence.

Fill one entry the week you do the session.
